# Archived experiment source

`CelebA_Privacy_Utility_and_Scaling.ipynb` is the superseded serial CelebA implementation. It is retained for the experiment's initialization history and source provenance. The reported run migrated its first 214 completed fits into the three current parallel workers; those saved result records remain required inputs when resuming that recorded run.

This notebook is **not a current execution entry point**. Use the six notebooks in `../notebooks/`, beginning CelebA shared preparation with `CelebA_P50.ipynb`. The public P50 notebook now includes preparation without utility training for a fresh installation; see `../docs/EXPERIMENTS.md`.

The archive preserves the original cell source while removing saved outputs and execution metadata. Original file hashes and code-cell hashes are recorded in `../docs/FRESH_START_SOURCE_MANIFEST.json`.
